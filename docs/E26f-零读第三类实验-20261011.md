## 1. 问题定义

E26e 终态(1:1、k16、无 C):FCFS 48.8%(A 7.5%/B 90%)、mpcS 60.0%(A 20%/B 100%)、EDF 18.3% 垫底。本实验加入 C 类回答三个新问题:

1. **C 的填空与排队死**:C 零读取(不占带宽)且单条仅 ~48ms 纯算,理论上应被任何调度器"免费"塞进空闲 NPU;但 FCFS 下 A 洪水使队列深,C 排队 >144ms(=192.7ms 期限−48.2ms 计算)即死——**零读类在坏调度下也会死,好调度下应≈100%**。
2. **C 的挤出**:C 恒占 ~4.7 个 NPU(98/s×48.2ms),A/B 的 worker 竞争加剧;A 的救活率与 B 的 100% 是否保住。
3. **EDF 的结构变化**:C 的期限(192.7ms)**早于 A**(198.5ms,C 无首层读故 T0 更短)——期限序里 C 排 A 前,但 C 零读不占带宽配额(bw_demand 的 d=V/c=0,恒轻流)——EDF 的"洪水"被零读墙稀释后还垫底吗。

## 2. 负载设计:D1f(三类混合)

### 2.1 C 类构造(标定复用 E26_PROFILE,零新自由度)

C = **零命中纯计算**类:h_tokens=0(读取量 V=κ·h=0),u_tokens 解方程使每层计算**恰等于 A 的 6.02ms**(与 E26 标定同一公式/同一参数):

```text
c(u, h=0) = t_launch + a·u/η(u) + b·u(u+1)/2 = 0.00602 s
η(u) = 1.0 若 u ≥ N_sat=512,否则 max(eta_floor, u/N_sat)
解(u 整数,二分):u_C = 2657 → c = 0.006021030 s(命中 6.02ms,差 1.0μs)
C_CLASS = (0, 2657)
```

- **T0_C = 8×c + 首层读(=0) = 48.17ms**;α=4 → **C 期限 192.7ms,比 A(198.5ms)早 5.8ms**——设计使然(C 无首层读),非调参。
- **选 A 型(6.02ms)不选 B 型(28.59ms)的量化理由**:B 型 C(u≈4080+)会把总计算推到 ~60.6 NPU·s → 计算下限 1.89s > 存储下限 1.71s,**计算翻转为主瓶颈**,稀释带宽调度差异、背离 E26 主线;A 型下总计算 39.0 NPU·s(下限 1.22s)< 存储 205.6 GB(下限 1.71s),**存储保持唯一主瓶颈** ✓。

### 2.2 生成规则(D1c 的三流扩展)

单 PCG64(seed)顺序抽三条独立随机流(CRN:同格点全臂同一份):

- **A 簇流**:簇心间隔 ~Exp(k/λ_A) iid,每簇心恰 k=16 条 A 同刻到达(rid 连续),余数入末簇(7×16+8)——**与 E26e D1c 完全同构**(用户指定 k=16);
- **B 泊松流**:间隔 ~Exp(1/λ_B) 每次 1 条(E26e 口径);
- **C 泊松流**:间隔 ~Exp(1/λ_C) 每次 1 条(新增,与 B 同构——唯一新变量是"存在零读类",控制变量)。

| 参数 | 值 |
|---|---|
| A:B:C | **1:1:1**(120+120+120=360 条) |
| λ_A=λ_B=λ_C | 98/s(每类;总到达率 294/s,到达期 ≈1.22s)——保持 A 供给过剩语义(98>85 条/s 吞吐上限) |
| α / 规模 | 4 / 360 条;T0 引擎解析式;deadline=arrival+4×T0 |
| 期限宽度 | A 198.5ms、B ~916ms、**C 192.7ms(最短)** |

seed 约定:`seed = 400 + 基号×8 + rep`(沿 e26.d1_seed;**D1f 基号 2** → rep0=416)。注:D1f 与 D1c 的流不可逐位同(RNG 抽取序列不同),与 E26e k16 的对照走分类统计口径,不走逐流口径。

### 2.3 预计算预测(跑前写死)

| 场景 | 预测 |
|---|---|
| 物理下限 | 存储排空 ≥205.6GB/120=1.71s;计算 ≥39.0/32=1.22s → makespan ~2.0~2.6s;存储主瓶颈不变 ✓ |
| FCFS | A 簇洪水照旧(A≈5~8%,worker 被 C 挤后更差);B ≥85%;**C 排队死:深队列期到达的 C 排队 >144ms 即死,C-SLO 预计 70~95%**(非 100%) |
| EDF | 期限序 C 最短 → 队首混入零读 C(占 worker 48ms/条、不占带宽)→ A 洪水被稀释但期限结构不变 → 预计仍垫底,A-SLO 或略升 |
| local/mpc | GuardedEDFBW 对 C 恒派(d=0 恒轻流);MPC 错峰 A + C 填空隙 → **C≈100%、B 保持 100%、A 保持 ~20%(±挤出 2~5pp)** |
| 簇冲击 | MPC ≤5/簇;FCFS 峰 16=k(沿 E26e) |

### 2.4 预注册假设

- **H1**:A-SLO 上 mpcS−FCFS ≥ +10pp(带宽错峰对 A 的救活在 C 存在下保持;挤出容忍 ±3pp)。
- **H2**:C-SLO 排序 mpc≥local≥FCFS,且 **mpc 的 C-SLO=100% vs FCFS 的 C-SLO<100%**(零读类的排队死假说)。
- **H3**:mpc 的 B-SLO 保持 100%;FCFS 的 B-SLO ≥85%。
- **H4**:总 SLO 排序 mpcS≥mpcT≥local≥FCFS≥EDF(EDF 仍垫底)。
- **H5**:簇冲击响应不变(MPC ≤5/簇、FCFS ≈k/2 均值峰 k);θ=S≥θ=T 或打平(沿 E26e)。
- 备用旋钮(H1 不达时先冒烟再入矩阵):C 率减半(49/s,挤出减半)或 C 数量减至 60。

### 8.2 C 类构造与 D1f 生成器伪码(含 RNG 与三流规则)

```python
def solve_c_u(target=0.00602):        # 二分整数解,单测锁 c∈[target−2e-6, target]
    ...                                # c(u,0)=t_l + a·u/η(u) + b·u(u+1)/2

def d1f_specs(k, seed, alpha=4, n=120, lam_each=98.0):
    """三流:单 PCG64(seed) 顺序抽 A 簇(同 d1c)→B 泊松→C 泊松。
    合并按时刻稳定排序(同时刻 A 簇在前→rid 连续);三类各 n 条。"""
    rng = np.random.Generator(np.random.PCG64(seed))
    t, a_times, centers = 0.0, [], []
    while len(a_times) < n:                       # A 簇流(k=16)
        t += rng.exponential(k / lam_each)
        m = min(k, n - len(a_times))
        a_times += [t] * m; centers.append(t)
    b_times = []; t = 0.0
    while len(b_times) < n:                       # B 流
        t += rng.exponential(1 / lam_each); b_times.append(t)
    c_times = []; t = 0.0
    while len(c_times) < n:                       # C 流(与 B 同构)
        t += rng.exponential(1 / lam_each); c_times.append(t)
    events = ([(x,"A") for x in a_times] + [(x,"B") for x in b_times]
              + [(x,"C") for x in c_times])
    events.sort(key=lambda e: e[0])               # 稳定,同刻 A 在前
    # → RequestSpec(rid,h,u,cls,T0=make_T0(...),deadline=arrival+α·T0)
    #   C 的 spec:h=0,u=2657;make_T0 对 V=0 的行为由单测锁定(首层读 0)
```

seed:`seed = 416 + rep`(基号 2,沿 e26.d1_seed)。CRN:同格点 5 臂共用同一份 specs(生成一次循环使用)。

## 9. 局限

- D1f 与 E26e k16 不可逐流对照(RNG 序列不同)——对照走分类统计;E26e k16 单 seed 方差(k4 上 A 类极差 28pp)提示本实验单 seed 结论也需补测规则兜底。
- C 选 A 型计算已论证(B 型翻转瓶颈);若读者要 B 型 C,属新格点(附 §2.1 数字)。
- C 期限早于 A 是构造使然(无首层读),读结果时须记住 EDF 的期限序含此偏置。
- 360 规模、单 λ(每类 98/s)单 α(4);C 的到达形态只取泊松单条(未扫 C 突发)。
- MPC 成本仍高(并行后 mpcS 预计 4~6h);若超 8h 用 E26F_TOTAL 缩放并披露。
