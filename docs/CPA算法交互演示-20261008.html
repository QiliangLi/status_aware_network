05局限（不回避）

  1. 过渡区误差：k∈[2,7] 层0阻塞+到期提升级联使闭式低估 ≤1.6ms（k≥8 全饱和段与 k=1 精确）——存活判定用 3ms 安全边际补偿；
  2. form 的在线近视：未见未来到达，多轮耦合下 96 规模 94/96 vs rollout 96/96——零推演的代价被量化而非隐藏；
  3. 对称类保证 / 普适性边界（20261008 质疑回应）：本问题族四目标（M/S/T/R）已证逐个 NP-hard（3-PARTITION→M/S 强；1|rᵢ|ΣCᵢ→T；LSV08→R，见 docs 既有分析）。CPA 解的是消掉了归约困难成分的特例（n_max=1 无批选择、类内同形同期限、突发同刻）——对称塌缩把指数决策空间变成 O(m²) 计数，公式是塌缩空间的结构解，不是一般最优公式。mooncake 实证（212 请求 233 种形状、d=V/c 跨 4 个数量级、n_max=8）：无守卫 v3.2 form 40.6%，比 BW 底座 61.3% 低 20.7pp（规则退化为 V 降序贪心）；v3.3 起内置适用域守卫（最大桶 <2 条即无可互换对 → 回退底座），mooncake 上与底座逐位一致（61.3%），E26c 对称工况逐位不变（158/192、guard=0）。异构域的正确排序：底座 61.3 < mpc 62.3（conversation）/ 32.4 < mpc 41.6（toolagent）。
  4. OPT 的受限决策点：离线穷举只在批完成/到达时刻决策（好计划本就如此，但严格最优性声明仅在该受限集上成立）；n≤10~16 可穷举，更大规模以 DPO+结构论证替代。
